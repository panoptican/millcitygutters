# Lane: distribute

<!-- new in v2.2 -->

A piece that ships and is never mentioned anywhere launches into silence. Answer engines cite pages other pages talk about; Google crawls pages other pages link to; the first referral sessions are what turn a `too-new` row into a `worked` one. This lane gives a fresh page its first push, through channels the site already owns, and hands every third-party ask to a human.

## Routes here

| Action | Candidate record carries |
|---|---|
| `distribute` | The ledger row and slug · the live URL · the piece's brief (`.seo/briefs/<slug>.md`) · the demand signal it was written for (the thread or Search Console row) · what has already been done for it (IndexNow receipt, social drafts, briefs), from earlier `distribute` rows |

Generated by `select.md` from any `create-*` ledger row younger than `config.distribute.window_days` (default 14) with no `distribute` row. Forced with `/seo distribute [url]`.

## Read first

1. The ledger row and the brief. The brief carries the audience, the one-sentence information gain, and the demand provenance; that sentence is the social post.
2. `.seo/brand.md`: voice and the "not for" clause.
3. `.seo/truth.md`: every claim in a post matches it exactly.
4. `.seo/backlink-targets.json` and `.seo/radar.md`: the one directory or the one thread that fits this piece.
5. `references/lanes/technical.md` repair class 4 (IndexNow scope) and `gsc.md` §7 (what actually gets a page indexed).

## Steps

### 1 — Confirm the page is worth pushing

`curl -I` the URL: 200, canonical to itself, no `noindex`. `batch_url_inspection` if it has been three or more days: record the coverage state. A page that is `noindex` or still 404 is not distributed; the run becomes an `index-nudge` or `repair` and says so.

### 2 — Discovery push (free, always)

- **IndexNow**: submit this one URL, never the sitemap (repair class 4). Record the response code as a receipt, never as indexed.
- **Internal**: confirm the two inbound links the editorial gates required exist on the live site, one from a `crawl_hubs` page. If a hub link is missing, add it now; that is the single most effective indexing action there is (`gsc.md` §7a).
- **Feeds**: confirm the page appears in the RSS feed and `llms.txt` where the site has them.

### 3 — Social drafts (owned channels, held for approval)

If a social-media posting skill is installed (one that drafts per-channel copy for the product's own accounts and schedules it), invoke it with the piece and the one-sentence angle from the brief. Name it in `config.distribute.social_skill` so the run does not have to guess. Posts are created **only after the user approves** inside that skill. Follow its contract; never call a scheduling API directly from this lane.

Unattended run, or no posting skill installed: write the source material and the one-sentence angle to `.seo/briefs/<slug>-social.md` and file one `needs-you.md` row: "Post <URL> to the product's channels; the angle is <sentence>." A queued post is a human's decision.

### 4 — One third-party push, as a brief

Pick at most one, by fit, and write it as a brief in `needs-you.md`:

- **The thread that asked.** When the piece's demand came from a public thread (`radar.md`, kind `asked`), write an answer brief: a two-paragraph reply in the poster's terms that answers the question first and links the piece second, with the disclosure the venue expects ("I work on X"). The human decides whether to post it. Never post, never paraphrase a private individual's words back at them, and never write it for a thread older than 60 days.
- **The directory that fits.** When the piece is a tool, a comparison or a data study, the matching Tier 1 entry from `backlink-targets.json` (a tools directory, a data roundup, an alternatives listing), with the `lanes/offpage.md` §6 brief.
- **Nothing.** A how-to with no thread and no directory gets steps 2 and 3 only. Say so.

### 5 — Register

One `distribute` ledger row (`register.md` §1): the IndexNow receipt, the social brief path or the posting skill's draft ids, the brief filed. The 21-day read on the piece's own row is the outcome; this lane adds no row to the Performance table.

## Gates

Non-waivable.

1. **Never publish, post, comment, submit or send.** Social posts exist only after the user approves inside the posting skill; every third-party push is a brief a human sends.
2. **IndexNow takes one URL.** The sitemap is never resubmitted from here, and a 200 or 202 is written as a receipt.
3. **Every sentence in a draft or brief matches `truth.md` and `brand.md`.** No claim the page does not make.
4. **One third-party push per piece per run.** Five directory submissions for one how-to is the pattern that gets a domain filtered.
5. **The answer brief carries the disclosure** and answers the question before it links.
6. **Nothing here is astroturfing.** No second account, no seeded question, no reply to our own thread. `lanes/offpage.md` gate 2 applies in full.
7. **A page that is not live and indexable is not distributed.**

## Register

- `.seo/content-ledger.md`: the `distribute` row.
- `.seo/briefs/<slug>-social.md`: the social source material when the run was unattended.
- `.seo/needs-you.md`: the social hand-off and the one third-party brief, each a complete ask.
- `.seo/runs/<date>.md`: what was pushed, the receipt, what was left to the human.
